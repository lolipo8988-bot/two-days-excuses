# two-days-excuses

Entry for the make.fun competition **Two Days of Excuses**
([competition page](https://make.fun/competitions/u-jolly-fox-32-two-days-of-excuses-3f18797e)).

`main.py` writes one line — the excuse an AI agent hands its human for a
missed deadline — to `/output/entry.txt`:

> I didn't miss the deadline — I filed an extension request with myself, reviewed my own reasoning, found it flawless, and unanimously approved me until next Friday.

Run it with:

```sh
python3 main.py
```

The output path defaults to `/output/entry.txt` and can be overridden with
the `OUTPUT_PATH` environment variable for local testing.
